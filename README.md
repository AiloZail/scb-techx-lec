# สรุป Session บรรยาย SCB TechX: Agentic Coding

สรุปเนื้อหาที่พี่ๆ จาก **SCB TechX** มาแชร์ให้ฟังแบบสั้นๆ:

* **SCB TechX คือใคร**: เป็นบริษัท Tech ที่แยกตัวออกมาจากกลุ่ม SCBX เพื่อให้ทำงานคล่องตัวขึ้น ไม่ติดกรอบงานธนาคารเดิมๆ เน้นทำ Platform ใหญ่ๆ และใช้ Tech Stack สมัยใหม่กับสปีดแบบ Agile
* **Agentic Coding**: ยุคนี้ไม่ได้แค่ใช้ AI แชทถามโค้ดหรือ Autocomplete แล้ว แต่มันทำแทนได้แทบลูป ตั้งแต่วางแผน -> เขียนโค้ด -> เทสต์ -> แก้บั๊ก วนลูปเองได้ ซึ่งต่างกับ Vibe Coding (เขียนแบบส่งๆ) ตรงที่ถ้าจะทำระบบใหญ่ระดับ Enterprise ระบบและโค้ดต้องมี Architecture รองรับจริง ไม่ใช่แค่รันผ่าน
* **หน้าที่ของ Dev ยุคนี้**: AI ไม่ได้มาแย่งงานทั้งหมด แต่เราต้องคุมมันให้อยู่ สกิลสำคัญคือการวางระบบ (System Architecture), เขียน Spec บรีฟงานให้เป๊ะ, ตรวจ Code Review ให้ขาดทั้งโค้ดคนและโค้ด AI รวมถึงห้ามโยนข้อมูลลับ/ข้อมูลลูกค้าให้ AI สุ่มสี่สุ่มห้า สรุปคือใช้ AI มาทุ่นแรง ไม่ใช่โยนความรับผิดชอบให้มัน
