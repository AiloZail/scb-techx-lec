# SCB TechX Guest Lecture Summary

สรุปสาระสำคัญจากการบรรยายของ **SCB TechX** ในหัวข้อ **Agentic Coding**:

* **SCB TechX Overview**: บริษัทเทคโนโลยีในกลุ่ม SCBX ที่แยกตัวออกมาเพื่อความคล่องตัว เน้นพัฒนานวัตกรรมและแพลตฟอร์มขนาดใหญ่ (เช่น SCB EASY, PointX) ด้วย Tech Stack สมัยใหม่และการทำงานแบบ Agile
* **Agentic Coding**: การใช้ AI เป็นตัวแทนช่วยพัฒนาซอฟต์แวร์แบบครบวงจร (Plan -> Code -> Test -> Iterate) ต่างจาก Vibe Coding ทั่วไปตรงที่ต้องมีสถาปัตยกรรมรองรับและทำงานในระดับ Enterprise ได้จริง
* **Developer's Role**: มนุษย์ยังเป็นผู้ควบคุมหลัก โดยต้องเน้นทักษะการออกแบบระบบ (Architecture), กำหนด Spec ให้ชัดเจน, ทำ Code Review เสมอ และระวังความปลอดภัยของข้อมูล (Data Privacy) โดยใช้ AI เพื่อเสริมประสิทธิภาพ ไม่ใช่ปล่อยให้ AI รับผิดชอบแทนทั้งหมด
